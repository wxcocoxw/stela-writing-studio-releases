# Stela Writing Studio

Write manuscripts, novels, and screenplays in one desktop workspace for Windows and macOS.

[Website](https://writewithstela.com) · [Download Stela](https://writewithstela.com/download) · [FAQ](https://writewithstela.com/faq) · [Releases](https://github.com/wxcocoxw/stela-writing-studio-releases/releases)

## One workspace for your writing

- Organize manuscripts and novels into chapters and scenes, with planning notes beside the draft.
- Compile manuscripts to Word documents or book PDFs.
- Work with Fountain and Final Draft screenplays, and export paginated screenplay PDFs.
- Keep drafts in local files, with autosave, crash recovery, and save points.

## Optional AI on your terms

The Writing Assistant supports your own Gemini, OpenAI, or Anthropic API key. Choose the writing context and review proposed edits before applying them.

Stela also includes an opt-in local MCP server for compatible agents. Connect over HTTP or stdio to approved writing workspaces, control read-only or write access, and pause or revoke access. Pre-edit save points help preserve earlier drafts. Stela must be running for this local integration.

Writing context can be shared with the chosen AI provider or a connected agent when you use those optional features.

## Platforms and pricing

Stela is available for Windows x64 and macOS on Intel and Apple Silicon.

Stela is free during beta. No account is needed for local writing. Optional AI provider or connected agent-service charges may apply.
